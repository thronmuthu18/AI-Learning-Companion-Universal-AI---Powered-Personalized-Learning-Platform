# Llama 3.2 Prompt Engineering & Structured Output Contracts

All runtime prompt construction lives in [packages/ai-contracts/src/index.ts](file:///m:/ai%20learning%20companion/packages/ai-contracts/src/index.ts) and is validated via Zod schemas in [packages/validation/src/index.ts](file:///m:/ai%20learning%20companion/packages/validation/src/index.ts).

## Llama 3.2 Instruct Chat Template
Mobile ExecuTorch runners (`LlmModule` on Android, `TextLLMRunner` on iOS) receive exact Meta Llama 3.2 Instruct header tags generated by `formatLlama32InstructPrompt()`:

```text
<|begin_of_text|><|start_header_id|>system<|end_header_id|>

{system_prompt}<|eot_id|><|start_header_id|>user<|end_header_id|>

{user_prompt}<|eot_id|><|start_header_id|>assistant<|end_header_id|>

```

## Supported Structured Tasks
1. **Goal Interpretation (`buildGoalInterpretationMessages`)** -> `AIGoalInterpretationSchema` (`temperature: 0.2`, `maxTokens: 360`)
2. **Skill-Gap Explanation (`buildSkillGapExplanationMessages`)** -> `AISkillGapExplanationSchema` (`temperature: 0.3`, `maxTokens: 360`)
3. **Roadmap Advisory (`buildRoadmapAdvisoryMessages`)** -> `AIRoadmapAdvisorySchema` (`temperature: 0.35`, `maxTokens: 420`)
4. **Streaming Educational Tutor (`buildTutorMessages`)** -> plain streamed pedagogy (`temperature: 0.5`, `maxTokens: 512`)
